# Legal readiness · Germany

This is a preparation checklist, not a statement that the site already complies with every legal requirement.

The APP ATLAS public catalog uses GitHub Pages, includes links to third-party GitHub pages and may become a public-facing project portfolio. According to the official Bavarian guidance, public-facing websites are not automatically exempt from provider-identification duties solely because they are free. Review **§ 5 DDG** and **§ 18 MStV** to determine the applicable notice requirements.

## Before wider promotion
1. Determine who is the legal operator of the site.
2. Prepare any required Impressum with operator name, valid service address, and contact channel. Do **not** put private home details into an issue or unreviewed public commit.
3. Determine an appropriate privacy notice for GitHub Pages hosting, browser-local storage, any embedded applications and externally loaded resources. The main catalog has no analytics, but linked applications may use external scripts or APIs.
4. Verify all image, font, historical text, screenshot, repository, video and app licenses. Publishing a GitHub repository without a license does not automatically grant reuse rights.
5. Check whether a separate responsible person is necessary for journalistic/editorial materials.
6. When legal text is ready, add clearly named and easy-to-find links on the home page and each detail page.
7. Review accessibility, disclaimer accuracy, and accuracy of scientific claims.

Sources for review:
- https://verwaltung.bund.de/leistungsverzeichnis/EN/leistung/99000000025492
- https://www.gesetze-im-internet.de/ddg/__5.html
- https://www.ihk-nuernberg.de/ihr-unternehmen/rechtsinformationen-fuer-unternehmen/internetrecht-recht-des-e-commerce/impressumspflicht
