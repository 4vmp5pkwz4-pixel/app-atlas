# Unified Atelier workspace — 0.9.8 beta

The main application is the sole navigation shell for the learning trainer, converter, research lab, pronunciation dictionary and key atlas. Research, dictionary and atlas are lazy-loaded, persistent local document components in borderless auto-height frames. Their existing documents and calculation/registry engines are retained to avoid ID collisions, accidental scientific changes and full-page reloads. Standalone links remain available for backwards compatibility and opt-in sharing.

The parent sends the authoritative semantic palette, language, text size, input font, source/output heights, atlas height, panel split and physical layout. One Studio panel controls all applicable dimensions. Keyboard-only dimensions still apply only to the keyboard. Source and result panels scroll internally if explicitly resized. Text size acts on research source text and glyphs, while input font acts on form fields. The original theme and automatic geometry remain available. The existing Brahmi-only trainer chrome is retained; technical modules explicitly fall back to English in that mode.

Transfers are user-directed: exercise or selected phrase → research; selected converter text → research/dictionary; research source → converter or a supported Brahmi practice exercise; dictionary syllable → trainer or research; atlas sign → dictionary. No transfer silently resets learning progress; starting a new practice exercise is an explicit action. Experiment input, result and selection survive section changes in the same tab, not a browser refresh. Existing standalone sessionStorage handoffs still work. The adapter verifies message source and origin; on file:// the origin is opaque, so the source window identity is required. No external framework or service is added. External references open in a new tab. The offline ZIP includes the adapter and all module documents.

BFG's embedded view offers sections for symbolic structure, comparison, graph tunnelling, correlated losses and methods; the mathematical engine and data are unchanged. Browser checks cover theme propagation, shared geometry, preserved input/result, transfers, mobile bounds and immersive exit. Full physical headset/WebXR support is not claimed.
