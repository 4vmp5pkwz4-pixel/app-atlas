# Atelier Studio 0.9.7 beta

The Studio toolbar button opens a non-modal local control surface. Obsidian, Sapphire, Amethyst, Ruby and Emerald are five additional dark semantic palettes; Original restores the previous design. Controls include exercise width on wide screens, atlas maximum height, target height, independent physical/Brahmi track heights, target/input font size, dock maximum height, key row height and magnified inspect width. Each has an explicit Auto reset. Linking heights is enabled by default; independent mode is intentional. Custom oversized blocks may require internal scrolling on small displays. Auto remains the tested original adaptive layout, including the golden split. Presets are Auto, Golden, Reading, Typing; manually customized values remain local. No change to key mappings, lessons or BFG math. Fullscreen uses the browser API where supported; immersion hides the sidebar but retains exit and navigation via the existing lesson controls. This is not a native WebXR session or a headset-tested application.

Preferences are stored separately in brahmi-studio-v1; lesson progress is unchanged. The browser suite captures screenshots at desktop and mobile sizes and checks bounded geometry, persistence, keyboard invariants and selected semantic color contrast pairs. Browser screenshots and automated geometry checks do not establish subjective visual perfection or physical headset behavior.
