# Contributing ideas and reporting problems

Public bug reports and project suggestions are welcome via [GitHub Issues](https://github.com/4vmp5pkwz4-pixel/app-atlas/issues).

Include the project, device/browser, exact steps, expected/actual behavior and a minimally reproducing example when possible. **Never paste passwords, private information, proprietary training materials or tokens in a public issue.**

The repository currently has no explicit open-source license. Submitting a suggestion does not itself grant broad reuse rights to project content. Before accepting code contributions, the repository maintainer should establish a contribution and license policy.

For user experience issues, use the Bug report template; for new applications use Suggest an app or improvement.
