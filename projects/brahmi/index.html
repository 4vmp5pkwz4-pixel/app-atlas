Об этом проекте

Брахми — древняя письменность, а не отдельный язык. Многоязычный тренажёр предлагает 24 урока и несколько документированных раскладок Mac. Каждая клавиша сопоставляет физическую позицию, Unicode-брахми и учебную IAST. Надписи даны в современной учебной транслитерации, а не в виде факсимиле.

Новый полнофразовый атлас внутри тренажёра позволяет выбирать цитаты с источниками и сравнивать две Mac-раскладки без потери прогресса. Проект доступен в браузере. Используй кнопки ниже для запуска, просмотра исходников и скачивания. Для внешних приложений откроется отдельная страница GitHub Pages.

About this project

Multilingual Brahmi typing and epigraphy studio: Mac physical keys, Unicode Brahmi, IAST, 24 lessons, source-linked texts and local progress.

The inline Phrase Atlas connects whole Brahmi texts, IAST and key sequences across eight Mac layouts, with an optional second layout and explicit practice action. Open the project in a browser, inspect its source and download a copy below. External projects open on their own GitHub Pages sites.

Über dieses Projekt

Brahmi ist eine Schrift, keine einzelne Sprache. Das mehrsprachige Lernatelier bietet 24 Lektionen und unterschiedliche belegte Mac-Tastaturansichten. Jede Taste zeigt physische Position, Unicode-Brahmi und didaktische IAST-Umschrift. Inschriftentexte sind moderne Lernumschriften, keine Stein-Faksimiles.

Der neue Satzatlas im Trainer ermöglicht die Auswahl quellenbelegter Texte und den Vergleich zweier Mac-Belegungen, ohne den aktuellen Lernfortschritt zu verändern. Öffne das Projekt im Browser, sieh dir den Quellcode an oder lade eine Kopie herunter. Externe Projekte öffnen auf ihren eigenen GitHub-Pages-Seiten.
